Publish the current draft

Publishing snapshots the saved draft into an immutable release and points the site at it. It does not change what visitors see until PUBLIC_CONTENT_SOURCE=owner-studio is also set — the two are separate switches on purpose.

The version guard is deliberate: if the draft moved since you loaded this page, the publish is refused rather than releasing something you did not review.

Release history

Rolling back moves the pointer only. Nothing is deleted, and a release you roll away from can be rolled forward to again.
